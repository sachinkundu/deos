## What?

Build a small desktop web app to track expenses in euros. I can add, edit and delete an expense with a name, amount and category. I can filter by category and see the total for the list on screen. Keep my data when I refresh the page.

## Why?

Use a small app to test the full flow from an idea to a pull request with a working preview and clear proof. This is a canary, not a product release. Keep it to one desktop screen, with data saved in this browser. No login, phone layout or outside services are needed.

## Done when

* I can manage expenses, filter them and see the correct euro total.
* My saved expenses remain after a page refresh, and invalid entries show a clear message.
* The final pull request has a working preview and real browser screenshots that show the key behavior.
* The pull request is ready for human review. It does not need to be merged or released.
